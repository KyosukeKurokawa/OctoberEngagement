Engagements Question

When should you use a background image, and when should you use the <img> tag?

Use the <img> tag when the image is a core part of the page content or carries information that visitors need to see. Content images require an alt attribute for accessibility and search engines.

Use a background image when the image is decorative, structural, or styled styling. Background images do not affect accessibility and can be easily hidden or modified via CSS without altering the HTML structure.
