According to the instructor, what is the main difference between CSS Grid and CSS Flex?
CSS Grid is two-dimensional that manages both rows and columns simultaneously, while CSS Flexbox is one-dimensional that manages either a row or a column.
Who decides where a child goes on the page: the child or its parent? Explain using your three-column layout.
The parent container decides where the children go. For example, in a three-column layout, the parent container defines the structure and sizing, placing the three child elements into position.
