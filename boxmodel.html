Questions

1. What is the difference between block tags and inline tags?

Block tags start on a new line and take up the full available width of their container, whereas inline tags flow within a text line and only take up as much width as their content.

2. What is the margin, border, and padding?

  • Padding is the inner space between an element's content and its border
  • Border is the line surrounding that padding
  • Margin is the outer space that separates the element from other elements.

3. What are units of measurement you can use in CSS?

CSS measurement units include absolute units like pixels (px) and relative units like percentages (%), em, and rem.

4. When would you use a figure tag?

people use a figure tag to group self-contained content, such as an image, diagram, or code snippet that is typically accompanied by a caption figcaption.
