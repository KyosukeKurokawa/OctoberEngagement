Questions & Answers

1. What is normal flow in HTML?

Answer: Normal flow is the default way browser lays out HTML elements on a page. Block-level boxes stack vertically from top to bottom, and inline elements flow horizontally from left to right within their parent container.

2. What does float do? Why do you need to clear the float?

Answer: Float takes an element out of the normal flow and shifts it to the left or right, allowing text and inline content to wrap around it. We need to use 'clear' because a floated element is removed from the normal flow, which can cause subsequent block elements to unexpectedly move up beside it.

3. What do absolute, fixed, and relative do?

Answer

  • Relative: Positions an element relative to its normal position in the flow.
  • Absolute: Positions an element relative to its nearest positioned ancestor, removing it from the normal flow so it leaves no gap behind. It scrolls away with the page.
  • Fixed: Positions an element relative to the browser viewport. it leaves no gap, but it stays fixed in place even when the user scrolls the page.

4. How can you make nice navigation buttons for mobile devices?

Answer: Links are inline, they are only as big as their text. Setting display block on each link makes it a full-width box, and adding padding, a larger font size, and a background color makes it a large button.
